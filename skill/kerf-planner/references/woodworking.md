## 1. Actual sizes

Lumber is named by its rough-sawn size; what you buy is smaller. Always design with the actual size.

| Nominal (US) | Actual (in) |   | Nominal | Actual (in) |
|---|---|---|---|---|
| 1×2 | ¾ × 1½ | | 2×2 | 1½ × 1½ |
| 1×3 | ¾ × 2½ | | 2×3 | 1½ × 2½ |
| 1×4 | ¾ × 3½ | | 2×4 | 1½ × 3½ |
| 1×6 | ¾ × 5½ | | 2×6 | 1½ × 5½ |
| 1×8 | ¾ × 7¼ | | 2×8 | 1½ × 7¼ |
| 1×10 | ¾ × 9¼ | | 2×10 | 1½ × 9¼ |
| 1×12 | ¾ × 11¼ | | 2×12 | 1½ × 11¼ |
| 5/4×6 decking | 1 × 5½ | | 4×4 | 3½ × 3½ |
| | | | 4×6 | 3½ × 5½ |

Sheet goods, actual thickness:
- **Softwood or sanded plywood:** ¾ ≈ 23/32 (0.703″); ½ ≈ 15/32; ⅝ ≈ 19/32.
- **¼ plywood:** often 7/32 or 5.2 mm.
- **Baltic birch** is metric: 18 mm (0.709″), 12 mm, 9 mm, 6 mm.
- **MDF** is usually close to its nominal thickness.

When one sheet part fits between two others (a cabinet bottom between the sides), subtract the actual thickness. Mention that sheets vary and are worth measuring.

Metric timber is sold by its finished size:
- **UK:** CLS 38×63, 38×89; planed (PAR) 18×44, 18×69, 18×94, 18×144.
- **Australia and New Zealand:** framing 45×70, 45×90.

Check the local names with the person.

## 4. Joinery allowances

How a part's length follows from the design. Kerf adds the saw kerf itself; don't add it here.

| Joint | Part size |
|---|---|
| Butt joint, screws, pocket holes, dowels, biscuits, Dominos | Rail between legs = overall − 2 × leg thickness |
| Mortise and tenon | Rail = space between legs + 2 × tenon length (¾–1″ is typical for aprons) |
| Dado or groove (¼″ deep in ¾ stock) | Shelf = inside width + 2 × dado depth |
| Back set in rabbets | Back = inside size + 2 × rabbet depth |
| Half lap | Both parts at full length |
| Face frame, butt or pocket joints | Stiles full height; rails = width − 2 × stile width |
| Cabinet box, sides full height | Bottom or top between the sides = width − 2 × actual sheet thickness |
| Tabletop | Overhangs the base 1–2″ on each side, usually |

Drawers and doors:
- **Side-mount slides:** drawer box width = opening − 1″ (½″ per side); depth = the slide length; height = opening − about 1″.
- **Undermount slides:** follow the maker's spec, commonly opening − ⅝″.
- **Inset doors:** about 1/16″ gap all round, so door = opening − ⅛″.
- **Full overlay doors:** usually ½″ past the opening on each side.
- **Drawer bottoms in a ¼″ groove:** inside size + 2 × groove depth.

## 6. Shelf spans

Rough longest spans before a shelf visibly sags under books:

| Shelf | Longest span |
|---|---|
| ¾ plywood | 30–32″ |
| ¾ plywood with a 1×2 edge strip | about 36–40″ |
| 1× pine | 24–30″ |
| ¾ MDF | about 24″ |
| 2× lumber on edge, or a 2×10/2×12 shelf | 48″ or more |

In metric: 18 mm plywood spans about 750–800 mm, and 18 mm MDF about 600 mm.

Past these, add a middle support or stiffen the front edge.

## 7. Things Kerf doesn't model, and what to do

- **Glue-ups wider than a board** (tabletops, wide panels): one board part per strip, 1–2″ longer than the finished length for trimming. Size the strips so the widths add up past the finished width by about ½″ for jointing. Note the glue-up in the part names.
- **Rips:** a narrower strip from a board is still a board part; name it "Cleat — rip to 1½".
- **Rough hardwood by the board foot:** pick a board width and length to model it, e.g. "4/4 walnut, 6″ wide". Price each board as its board feet × the price per board foot; board feet = thickness × width × length in inches ÷ 144. Say it's an approximation.
- **Hardware, glue, finish, edge banding:** list them in the notes, not the project.
- **Spares:** construction lumber has knots and warps. Suggest one spare board per material rather than adding one silently.
